# Big-Mart-Sales-Prediction
In this project I have
Developed a comprehensive Machine Learning pipeline using Python and Scikit-Learn for predicting sales across Big Mart outlets, and using feature engineering and advanced modeling techniques.
Implemented MLflow for model tracking and management, ensuring seamless version control and model staging from development to production stages.
Integrated Airflow for orchestration, automating the data processing, training, and deployment workflows to enhance operational efficiency and ensure daily model updates.
Utilized Docker for containerization, encapsulating the application and its environment to ensure consistency across development, testing, and production environments.
Configured Jenkins for continuous integration and continuous deployment (CI/CD), enabling automated testing and deployment pipelines that respond to Git repository changes, reducing deployment cycles and improving code quality.
Designed and deployed a Flask web application, providing a user interface for real-time sales predictions, enhancing user interaction and accessibility to the predictive system.
Employed best practices in code version control and collaboration using Git and GitHub, maintaining high standards of code integrity and facilitating team collaboration.
